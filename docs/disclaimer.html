1. 接口来源：全部为哔哩哔哩官方提供#

本项目调用的所有接口均为哔哩哔哩官方提供并公开的接口，不存在私有接口、破解接口或绕过鉴权的接口。具体来源：

来源地址本项目用它做什么
哔哩哔哩开放平台文档https://open.bilibili.com/doc/4、https://openhome.bilibili.com/doc/4/data/*.json 里的 170 篇文档 / 100 个端点规格，全部由 scripts/build-spec.mjs 从官方文档抓取生成
开放平台业务域名member.bilibili.com带 2.0 签名（HMAC-SHA256）的开放平台业务调用
开放平台 OAuth2api.bilibili.com/x/account-oauth2/v1/*code 换 token、refresh_token 续期
开放平台上传域名openupos.bilivideo.com视频分片上传
主站 Web 接口*.bilibili.com（api.bilibili.com、www.bilibili.com 等）以使用者自己的浏览器 Cookie 身份调用官方 Web 接口

data/status-codes.json（118 个错误码）、data/mock.json（43 个沙盒 mock 接口）同样来自官方发布内容。

本项目只做「按官方规则把请求拼好、把响应读回来」这件事：不实现任何未公开的加密、 不伪造凭证、不破解客户端、不绕过验证码、不做风控对抗。请求头、签名算法、参数表都来自上述公开文档 与官方前端代码。

3. 凭据由使用者自备，缺失时功能受限#

本项目不内置、不收集、不上传任何凭据。两套凭据都由使用者自己放进本地文件：

凭据文件覆盖变量没有它 → 用不了
开放平台 client_id / app_secret / access_tokensecrets/open-platform.jsonBILI_CRED_FILE全部开放平台接口：bili_api_sign / bili_api_call / bili_upload_plan / bili_scopes / bili_oauth（除 help、status）
主站 Cookie（SESSDATA / bili_jct 等）secrets/cookies.jsonBILI_COOKIE_FILEbili_cookie / bili_web_call：登录态体检、导航栏、关系、黑名单、举报、投稿查询等一切主站 Web 调用

没有 BILI_COOKIE_FILE 和 BILI_CRED_FILE，上述功能一律不可用。 此时仍然可用的只有纯本地的部分：

  • bili_docs_search / bili_docs_list / bili_docs_get —— 检索本地已有的 170 篇文档规格
  • bili_quickstart / bili_error_lookup / bili_status_codes / bili_ws_protocol / bili_webhook / bili_scopes —— 本地知识查询
  • bili_codegen —— 生成调用代码（不发送请求）
  • bili_mock —— 打官方沙盒 mock（不需要任何凭据）
  • bili_oauth {action:"help"|"status"} —— 只看说明与凭据体检
  • bili_api_sign / bili_api_call {dryRun:true} —— 只演示签名结构与将要发出的请求

拿凭据的方式：

  • 开放平台：登录 https://open.bilibili.com → 实名认证 + 开发者入驻 → 应用管理 → 创建应用 → 拿 Client ID / Secret，再跑 npm run login 换 access_token
  • 主站 Cookie：浏览器登录 bilibili.com 后导出，再 bili_cookie {action:"import"}

两个文件所在目录已在 .gitignore 中排除，不要把 secrets/ 提交到任何仓库。

4. 账号安全与凭据泄露#

  • SESSDATA 等同于账号登录凭证。泄露它基本等于交出账号。 app_secret、access_token、refresh_token 同理。
  • 本项目默认对所有凭据做脱敏输出（SESSDATA 显示为 abcdef…wxyz [len=124]）， 只有显式传 reveal:true 才输出原值。不要随手开这个开关。
  • 请勿在聊天记录、Issue、截图、录屏、日志、CI 日志中粘贴真实凭据。 本仓库的 Issue 区是公开的。
  • 凭据文件以明文存放在本地。请自行确保磁盘加密、文件权限与备份安全。
  • 若不慎泄露：立刻在哔哩哔哩账号安全设置里退出所有设备并改密码， 开放平台凭据则在控制台重置 Secret / 撤销授权。本项目作者无法代你处理。
