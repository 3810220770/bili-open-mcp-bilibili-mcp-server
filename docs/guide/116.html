获取资源列表#

接口说明：通过该接口获取接入方返回的资源列表信息 demo_path(仅供参考)： https://{your_service_domain}/resource_list 请求方式：POST

Body 请求参数

json
{
  "page": 16,
  "page_size": 5,
  "biz_source": "bili",
  "request_id": "313b0f9976c4008e2c8a02737265795f",
  "biz_code":"bilibili_fgo",
  "open_id":"60b8cf87b2614ec7980f7935b8b00159"
  "start_time":1709712714,
  "end_time":1709712715,
}

B站发起请求参数#

名称位置类型必选中文名说明
biz_sourcebodystring是资源source用于标识业务方，当同一用户在第三方有多个业务接入时用于区分来源
request_idbodystring是请求idb站请求id，用于链路跟踪，建议日志记录该字段，方便后期追溯问题
pagebodyinteger是页码页码
page_sizebodyinteger是每页数据量每页数据
biz_codebodystring是三方业务码三方业务码，用于区分同一个业务方的不同应用
open_idbodystring否open_id用户在该应用下的唯一ID
start_timebodyint64否起始时间请求资源时间范围开始时间的时间戳
end_timebodyint64否结束时间请求资源时间范围结束时间的时间戳

与接入方错误码约定#

错误码含义B站侧处理逻辑
0成功
-1000资源不存在返回给上游业务
-1100内部错误返回给上游业务
-1200其他错误（请在message中简要描述错误）返回给上游业务
-1300并发限制返回给上游业务
-1400用户无权限返回给上游业务
