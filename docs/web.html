隐藏能力 · 主站 Web

开放平台（open.bilibili.com）只放出已商务合作的能力，文档自己也写着「其它能力不走文档，请发邮件咨询」（见 170_文档中未列出的功能）。剩下那一大片 —— 举报、拉黑、动态、评论、收藏、历史、消息、直播、创作中心 —— 都在主站 www/api.bilibili.com 与 api.live.bilibili.com 上，走浏览器 Cookie，不走 2.0 签名。这一页把它们收齐：方法、地址、参数、返回码、实测状态、坑，一条不落，全部可以通过 bili_web_call 直接调。

!
实测状态
每条状态都是无 Cookie、无签名直接 GET 拿到的真实返回，由 npm run web:probe 复现。写操作（POST + csrf）不静默调用，一律标「未实测」。 核验时间 2026-10-31，脚本 scripts/probe-web.mjs（npm run web:probe）。

主站体系只认 Cookie（SESSDATA / bili_jct 等），与开放平台的 client_id + secret + HMAC 签名互不通用。写操作会自动补 csrf=bili_jct；/wbi/、/polymer/、/v2/reply/wbi/ 路径会自动算 w_rid + wts。

公开可调 需 Cookie 需 wbi 有风控 可能私有 已失效 二进制/XML 写操作
