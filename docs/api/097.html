售后列表查询

POST#97api SHOP_AFTERSALES_INFO
https://member.bilibili.com/arcopen/fn/market/common/after_sale_query_list

开放能力 / 交易电商 / 电商 / 接口 / 售后模块接口

调用该接口可查询退货列表

body 参数

名称类型必填说明
order_idint否父订单号
after_sale_typeint否售后类型: 1-仅退款；2-退货退款；3-换货；
reasonint否售后理由；1-七天无理由退货；2-非七天无理由退货；
logistics_statusint否退货物流状态，枚举为1(全部),2(已发货),3(未发货)
refund_typeint否退款类型:0-无需退款；1-原路退款；2-线下退款；
arbitrate_statusint否仲裁状态：0-默认状态；1-待商家上传凭证；2-双方举证中；3-平台仲裁中；61-买家撤销仲裁；62-系统撤销仲裁；8-仲裁完成
start_timeint否申请时间开始，单位为秒（查询范围包含开始值）
end_timeint否申请时间结束，单位为秒（查询范围不包含结束值）
amount_startint否售后退款金额下限，单位为分（查询范围包含开始值）
amount_endint否售后退款金额上限，单位为分（查询范围不包含结束值）
order_bystring否排序方式，优先级按照列表顺序从前往后依次减小，写法为"<字段名称> <排序方式>"，字段名称目前支持"apply_time"（申请时间）和 "update_time"（更新时间），排序方式目前支持"asc"（升序）和"desc"（降序）。
pageint是页数，从0开始
sizeint是每页数量，最多100个
after_sale_idint否售后单号
after_sale_statuslist否售后状态：1-申请退款；2-取消退款申请；3-拒绝退款申请；11-申请退货退款；12-取消退货退款申请；13-拒绝退货退款申请；14-待用户提交物流；15-待商家确认收货；21-申请换货；22-取消换货申请；23-拒绝换货申请；24-换货待商家发货；25-换货发货，待买家确认收货；60-售后完成；61-售后终止；
update_start_timeint否更新时间开始，单位为秒（查询范围包含开始值）；当使用update_start_time和update_end_time时，order_by= update_time；
update_end_timeint否更新时间结束，单位为秒（查询范围包含开始值）；当使用update_start_time和update_end_time时，order_by= update_time；
