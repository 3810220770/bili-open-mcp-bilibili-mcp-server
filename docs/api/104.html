库存更新

POST#104api SHOP_STOCK_INFO
https://member.bilibili.com/arcopen/fn/v2/market/stock/update

开放能力 / 交易电商 / 电商 / 接口 / 库存模块接口

调用该接口可更新库存

body 参数

名称类型必填说明
modify_stock_listlist是库存更新列表
sku_idint是bilibili商品ID（SKU）
zp_entity_stock_offsetint是model=1时增量更新当前可售库存值；model=2时全量更新当前可售库存值；
modeint否库存更新模式：1.增量更新 2.全量更新 默认为1

响应字段

名称类型必填说明
failed_skuslist是失败列表
messagestring是失败信息
stock_idint是-
